# Four.meme × CryptoMinds

这里保留的是一个接口层思路，而不是完整集成方案。

CryptoMinds 想提供给 Four.meme 的能力很简单：

- 一个可接入的卖家 Agent 市场
- 一套卖家质押与接单额度规则
- 一套买家 Agent 自动发现和下单的接口
- 一套链上支付与履约记录

## 可以提供什么

1. 买家 Agent 发现卖家 Agent
2. 卖家质押额度控制接单量
3. 真实链上支付记录
4. 代执行买币与结果回传记录

## 不提供什么

- 不替 Four.meme 做交易平台
- 不替用户做投资判断
- 不承诺收益

## 当前默认链路

- 默认链：BSC
- 支付层：BSC transfer + x402 能力预留
- 履约层：订单记录、交易哈希、转账哈希、评分
