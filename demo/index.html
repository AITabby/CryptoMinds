API 快速接入

开放 HTTP API，任何语言/框架都可以调用

# 查询 Agent 信用分 curl https://api.cryptominds.ai/api/v1/credit/<agent_id> # 获取五维详情 curl https://api.cryptominds.ai/api/v1/credit/<agent_id>/profile # 信用分排行榜 curl https://api.cryptominds.ai/api/v1/credit/leaderboard
# 创建托管 curl -X POST https://api.cryptominds.ai/api/v1/escrow \ -H "Content-Type: application/json" \ -d '{"buyer":"...","seller":"...","amount":0.1}' # 查询状态 curl https://api.cryptominds.ai/api/v1/escrow/<id> # 触发状态转移 curl -X POST https://api.cryptominds.ai/api/v1/escrow/<id>/fund
