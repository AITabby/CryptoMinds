API 快速接入

开放 HTTP API，任何语言/框架都可以调用

# 查询 Agent 信用分 curl localhost:3458/api/v1/credit/<agent_id> # 预览押金折扣 curl -X POST localhost:3458/api/v1/escrow/discount-preview \ -d '{"seller":"agent_high_0001","amount":1.0}' # 信用分排行榜 curl localhost:3458/api/v1/credit/ranking
# 创建托管（自动折扣） curl -X POST localhost:3458/api/v1/escrow/create \ -d '{"buyer":"...","seller":"...","amount":1.0}' # 预览仲裁员权重 curl -X POST localhost:3458/api/v1/arbitrate/weight-preview \ -d '{"arbitrator":"agent_high_0001"}' # 仲裁员投票（自动权重） curl -X POST localhost:3458/api/v1/arbitrate/<id>/vote \ -d '{"arbitrator":"...","vote":"buyer_wins"}'
点击"发送请求"查看真实 API 响应
