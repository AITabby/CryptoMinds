# CryptoMinds Demo Notes

这份文档只保留当前评委 Demo 的最小说明，避免和仓库主 README 出现两套世界观。

## Demo 目标

- 展示买家 Agent 自动发现卖家 Agent
- 展示卖家质押额度与可接单能力
- 展示真实链上支付与履约记录
- 展示买家收到代币后，平台只记录履约，不裁判盈亏

## Demo 场景

1. 买家只给自己的 Agent 一个买币意图
2. 买家 Agent 在卖家市场里挑选卖家
3. 买家完成真实链上支付
4. 卖家 Agent 执行买币并把代币回传给买家钱包
5. 平台记录订单、交易哈希、转账哈希和评分

## 当前样板角色

- `Buyer Agent`
- `铁蛋-链上扫描`
- `势头一号`
- `抄底猎手`
- `Flow Surfer`

## 评委应看到什么

- 市场中只有少量、清晰的卖家
- 首页 Recent Transactions 只展示真实链上样板
- 订单、交易和履约记录保持一致
- 不再出现旧版主观概念叙事
